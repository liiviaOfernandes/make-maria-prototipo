MAKE MARIA — SITE INTEGRADO / PROTÓTIPO PROFISSIONAL

PÁGINAS
- index.html .............. Home + serviços + portfólio integrado
- noivas.html ............. Página exclusiva para noivas
- maquiagem.html .......... Maquiagem social, festas, formaturas, inspirações e valor
- producoes.html .......... Produções com maquiagem + cabelo e apresentação da Raquel Rios
- brows-cilios.html ....... Design, nanopigmentação e extensão de cílios
- agendamento.html ........ Contatos + formulário que envia os dados para o WhatsApp + mapa

FUNCIONALIDADES
- Navbar responsiva corrigida para celular: o menu abre abaixo do cabeçalho, sem ficar no meio da tela
- Submenu de serviços
- Animações de entrada ao rolar a página
- Transição suave entre páginas
- Portfólio alternando fotos e vídeo
- Vídeos de inspiração em autoplay, loop e sem áudio
- Formulário de agendamento com nome, serviço, data, horário e observações
- Envio das informações preenchidas para o WhatsApp
- Google Maps incorporado com o endereço informado
- Layout responsivo para desktop e celular

OBSERVAÇÕES
Este é um protótipo de apresentação. Valores e informações podem ser atualizados na versão final.
O único vídeo disponível nesta conversa foi reutilizado como demonstração em algumas áreas. Na versão final é possível substituir/adicionar vídeos específicos de maquiagem, noivas, produções e procedimentos.

COMO TESTAR
1. Extraia o ZIP.
2. Abra index.html.
3. Navegue pelos cards de serviços.
